# Planechaser - Game Expo project for Fall 2025

## About 
Winner of the 2025 Florida Poly Game Expo, *Planechaser* is a fast pace, *Doom*-like FPS where the player is able to "shift" between three different planes of existence which are denoted by solid colors (🔴 🔵 🟡).

Checkout our [itch.io](https://chiefb-radgrant.itch.io/planechaser) page!
